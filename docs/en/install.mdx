# Install

Use the following steps to install the component.

## Downloading

:::info
To use Hosted Control Plane, you need two Cluster Plugins from Customer Portal.
1. **Alauda Container Platform Cluster Bootstrap Provider** (previously **Alauda Container Platform Kubeadm Provider**)
2. **Alauda Container Platform Hosted Control Plane Cluster Provider** (previously **Alauda Container Platform Hosted Control Plane**)
3. **Alauda Container Platform Hosted Control Plane Worker Node Provider** (previously **Alauda Container Platform SSH Infrastructure Provider**)

Starting in ACP 4.5, these Cluster Plugins and the etcd operator app below have new names. Search for the new names when you download them from the Customer Portal. A package published before the rename still shows the former name in the platform after you upload it.
:::

:::info
To deploy etcd operator, you need to download the app named **Alauda Container Platform Control Plane Database Operator** (previously **Alauda Build Of etcd Operator**) from Customer Portal.
:::

## Uploading

Upload the downloaded packages to the platform with the `violet` tool.


## Installing

Install the Cluster Plugins from **Administrator** > **Marketplace** > **Cluster Plugins**.
